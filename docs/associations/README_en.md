# RAG Context File – Audierne 2026

## Category: Associations & Local Life

Version 1.1 – February 05, 2026  
Main source: Audierne 2026 participatory program section

### Key Observations

- Dynamic and vital local associative network.
- Need for stronger logistical and financial support.
- Lack of coordination among associative actors.

### Current Proposals (participatory – evolving)

1. **Strengthen support for associations**
   - Simplify administrative procedures.
   - Easier access to municipal premises.
   - Dedicated participatory budget for associative projects.

2. **Create a House of Associations**
   - Shared space to foster synergies between groups.
   - Pooled logistical support (equipment, resources…).

### Complementary Local Context

- Around **250 associations** active in Cap Sizun (sports, culture, leisure, social, heritage…).
- Annual Cap Sizun Associations Forum (e.g. September 13, 2025 in Pont-Croix; previous joint editions with Audierne, Plouhinec, Pont-Croix).
- 2024-2025 Associations Directory (themed: leisure, culture, sports, social…).
- Recurring needs: suitable premises, stable funding, resource sharing, administrative simplification.
- Support networks: Guid'Asso 29, Le Compte Asso, French State services in Finistère.
