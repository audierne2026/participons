# Contexte RAG – Audierne 2026

## Catégorie : École & Jeunesse

Version 1.3 – 05 février 2026  
Source principale : https://audierne2026.fr/programme/#école--jeunesse  
Initiative : Plateforme citoyenne participative Audierne-Esquibien 2026

### Nos constats (issus du programme)

- Importance de l’accompagnement éducatif de qualité.
- Enjeux de mobilité pour les jeunes.
- Besoin d’activités périscolaires diversifiées.

### Propositions en cours (participatif – évolutif)

1. **Soutien aux écoles publiques**
   - Équipements adaptés et entretenus.
   - Dialogue constant avec les équipes éducatives et les parents.

2. **Activités pour les jeunes**
   - Développement de l’offre périscolaire et de loisirs.
   - Espaces dédiés aux adolescents.

**Vos idées :** Partagez vos priorités via le formulaire dédié.

### Contexte local complémentaire (sources externes 2024-2026)

- Écoles principales : École publique Pierre Le Lec (maternelle + élémentaire + ULIS, rénovation prévue 2026-2027 avec végétalisation cour), École publique Esquibien.
- Écoles privées : Sainte-Anne (catholique), Diwan (breton), autres dans le Cap Sizun.
- Collège : Bois de Locqueran (Audierne), Lamennais (privé).
- Accueil de loisirs (ALSH) : géré par Cap Sizun Animation (3-12 ans, mercredis + vacances, sites Audierne et alentours).
- Projets en cours : rénovation école Pierre Le Lec (chantier début 2026, rentrée 2027), débats sur regroupements scolaires passés, réseau écoles rurales Grand Cap.
- Mobilité jeunesse : enjeux transport scolaire rural, permanence SIJ (Structure Info Jeunesse) installée à Audierne (2025).
- Activités jeunesse : surf, sports, culture via associations Cap Sizun.
